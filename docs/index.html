Was ist die KPMN USB-Stick Suite?What is the KPMN USB-Stick Suite?

Die KPMN USB-Stick Suite ist eine Sammlung von USB-Sticks, die jeweils einen konkreten Zweck rund um IT-Diagnose, System-Wiederherstellung und Neuinstallation abdecken. Jeder Stick ist eine eigenständige, portable Windows-Anwendung mit einem eigenen dunklen Kpmn-Theme und eigener Akzentfarbe. AEGIS bindet sie alle zusammen: es erkennt angeschlossene Sticks live, verwaltet einen verschlüsselten Datei-Tresor, Vorlagen und Backups – und kann die anderen drei Sticks (AVAS, DART, MABS) direkt selbst bauen und aktuell halten.

Die Grundregel des ganzen Projekts: Kpmn Development hostet niemals Software Dritter. Installer, Treiber und Tools werden immer live von der offiziellen Herstellerquelle geladen – Kpmn Development verteilt ausschließlich seinen eigenen Code (AEGIS, AVAS, DART, das MABS-Theme).

The KPMN USB-Stick Suite is a collection of USB sticks, each covering a concrete purpose around IT diagnostics, system recovery, and reinstallation. Every stick is a standalone, portable Windows application with its own dark Kpmn theme and accent color. AEGIS ties them together: it detects connected sticks live, manages an encrypted file vault, templates and backups – and can build and update the other three sticks (AVAS, DART, MABS) itself.

The project's core rule: Kpmn Development never hosts third-party software. Installers, drivers and tools are always fetched live from the official vendor source – Kpmn Development only ever distributes its own code (AEGIS, AVAS, DART, the MABS theme).

Gitea-InfrastrukturGitea infrastructure

AVAS, DART und MABS liegen als fertige Releases auf einem selbst gehosteten Gitea-Server. AEGIS' Suite Builder lädt von dort ausschließlich die aktuellste Version – niemals Quellcode zum lokal Kompilieren, sondern fertige, self-contained Binaries, damit auch ein frisch aufgesetzter Ziel-PC ohne .NET SDK funktioniert.

AVAS, DART and MABS sit as finished releases on a self-hosted Gitea server. AEGIS's Suite Builder only ever downloads the latest version from there – never source code to compile locally, but a finished, self-contained binary, so a freshly reimaged target PC works even without the .NET SDK installed.

token ein Read-Only-Token reicht (und sollte auch nur ein Read-Only-Token sein) – AEGIS liest nur, es schreibt nie auf den Gitea-Server. a read-only token is enough (and should be the only kind used) – AEGIS only ever reads from the Gitea server, never writes to it.
◆ Warum ein eigener Gitea-Server?Why a self-hosted Gitea server? Alles, was hier liegt, wird automatisch auf andere Geräte übertragen, sobald jemand den Suite Builder benutzt. Deshalb gilt für Gitea eine strengere Regel als für AEGIS' eigenen Quellcode: nur fertig getesteter, wasserdichter Stand kommt hier rein – nie Zwischenstände oder work-in-progress. Everything that lives here gets carried onto other people's devices automatically the moment someone uses the Suite Builder. That's why Gitea follows a stricter rule than AEGIS's own source: only fully tested, watertight builds go here – never intermediate or work-in-progress states.

Suite Builder: KonzeptSuite Builder: concept

Für jeden Stick gibt es im Suite Builder eine eigene Karte mit Laufwerksauswahl und Build-Button. AEGIS unterscheidet automatisch zwei Modi, je nachdem, ob die aktuelle Laufwerksbezeichnung schon zum Zielstick passt:

Every stick gets its own card in the Suite Builder, with a drive picker and a build button. AEGIS automatically distinguishes two modes, depending on whether the drive's current volume label already matches the target stick:

ModusMode WannWhen VerhaltenBehavior
Neuer StickNew stick Laufwerksbezeichnung stimmt nicht mit dem Zielstick übereinVolume label doesn't match the target stick Laufwerk wird vollständig geleert, deutliche Warnung vorherDrive is fully wiped, clear warning beforehand
AktualisierenUpdate Laufwerk heißt schon so wie der Zielstick (z.B. schon "AVAS")Drive is already labeled like the target stick (e.g. already "AVAS") Nur die Programmdateien werden überschrieben, restliche Inhalte bleibenOnly the program files get overwritten, everything else stays
◆ SicherheitsnetzSafety net Das Laufwerk, von dem AEGIS gerade selbst läuft, taucht in keinem der drei Dropdowns auf – es kann also nie versehentlich als Ziel gewählt werden. The drive AEGIS is currently running from never appears in any of the three dropdowns – so it can never accidentally be chosen as a target.

MABS ist grundlegend anders: statt Dateien zu kopieren, installiert AEGIS hier Ventoy (Bootloader + Partitionierung) direkt auf den Datenträger. Das ist unwiderruflich – deshalb bekommt MABS die deutlichste Warnung im ganzen Suite Builder.

MABS is fundamentally different: instead of copying files, AEGIS installs Ventoy (bootloader + partitioning) directly onto the drive. That's irreversible – which is why MABS carries the most severe warning anywhere in the Suite Builder.

Sicherheit & PolicySafety & policy

  • Keine Software Dritter wird von Kpmn Development gehostet – jeder Download kommt live vom Hersteller.
  • Destruktive Aktionen (Neubau, Ventoy-Formatierung) verlangen immer eine explizite Bestätigung, die das genaue Ziellaufwerk benennt.
  • Das AEGIS-eigene Laufwerk ist in allen Build-Dropdowns unsichtbar.
  • Der Vault hat bewusst keine Passwort-Wiederherstellung – ein vergessenes Passwort bedeutet endgültigen Datenverlust.
  • No third-party software is hosted by Kpmn Development – every download comes live from the vendor.
  • Destructive actions (new build, Ventoy format) always require an explicit confirmation naming the exact target drive.
  • AEGIS's own drive is invisible in every build dropdown.
  • The Vault deliberately has no password recovery – a forgotten password means permanent data loss.
